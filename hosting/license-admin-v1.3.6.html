Migrasi ke cloud (sekali saja)

Saat pertama kali migrasi ke cloud, kartu Migrasi ke cloud muncul di tab Client. Urutannya: Export backup JSON dulu (wajib, tombol migrasi tidak aktif sebelum itu) → Mulai migrasi → Verifikasi migrasi (hitungan + detail) → Bersihkan data lokal. Client yang belum punya toko tetap tersimpan lokal + badge "belum pindah" sampai tokonya dibuat. Selesaikan migrasi di HP lama sebelum pindah HP.

Cara pakai Client

Tab Client menampilkan daftar client dari cloud. Cari lewat kotak Cari nama / kode / WA / Catatan, filter status, urutkan lewat kotak Urutkan. Tiap baris: nama toko, kode lisensi, paket, tanggal hangus, WA, status. Tombol: Salin kode, Lihat perangkat, Perpanjang, Cabut, Hapus. Label "Terakhir sync" menunjukkan kapan daftar terakhir diperbarui. Perangkat dibuka di dalam kartu client itu — bukan panel di bawah daftar.

Cara pakai Generator (Buat Client)

Pilih paket Trial (gratis 7 hari), Langganan (Rp150rb / 3 bulan), atau Lifetime (Rp350rb, beli putus). Isi nama toko, nama owner, nomor WA, email toko (wajib), catatan, klik Buat Client — toko + lisensi langsung tersimpan di cloud, client tinggal login Google lalu gabung pakai kode toko. Untuk kode lisensi yang sudah ada di Firestore tapi belum ada di daftar, pakai Tambah Client lama.

Cara pakai Perpanjang

Di card Client, klik Perpanjang. Kode lisensi sudah terisi otomatis. Klik +7 hari untuk Trial, +3 bulan untuk Langganan, atau isi tanggal manual. Klik Unlimited kalau Client upgrade ke Lifetime. Klik Simpan perpanjangan — langsung ditulis ke Firestore, tanpa tempel manual.

Cara pakai Pendaftar

Pendaftaran dari form Daftar Toko muncul di tab Pendaftar (badge merah = jumlah menunggu). Klik Lihat Detail untuk memeriksa, lalu SETUJUI & AKTIFKAN untuk membuat toko + lisensi otomatis, atau Tolak.

Cara pakai Setting

Setting berisi: Tema Aplikasi, Tentang APK.

Kalau ada masalah

  • Kode tidak valid di HP Client: pastikan dokumen licenses ada, field type dan status active, dan expiresAt belum lewat (kecuali Lifetime tanpa expiresAt). Perpanjang dari Dev menulis langsung ke Firestore — tidak perlu cek console lagi.
  • Tulis ke Firestore ditolak (permission-denied): kemungkinan rules baru (v1.3.6) belum dipublish di Console. Publish rules dulu, baru pakai fitur tulis.
  • Lupa password login: reset lewat Firebase Console (Authentication → pengguna miauwdesu.project@gmail.com → reset password). Data client tetap di cloud.
