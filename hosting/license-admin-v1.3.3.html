6. Pengaturan & kunci

Catatan kunci perangkat, jujur: Di file HTML ini, kunci = PIN + ID instalasi browser ini. Kalau file ini dibuka di HP/browser lain, browser itu kosong, jadi ia akan minta atur PIN baru. Kunci perangkat yang benar-benar mengunci ke satu HP hanya jalan di versi APK, karena APK bisa membaca Android ID HP itu. Di APK nanti: HP lain yang install APK akan tampil layar terkunci dan tidak bisa masuk tanpa PIN + file backup lama. Orang yang membongkar APK tetap bisa bypass secara teknis, karena kunci tersimpan lokal, bukan di server. Kunci server 100% perlu backend, itu di luar jalur lokal ini.
Data tersimpan lokal di HP/browser ini saja, bukan di Firestore. Dokumen lisensi tetap harus ditempel manual ke console. Kalau mencabut lisensi di sini, ubah juga status di console jadi revoked, kalau tidak, HP Client tetap menganggap kode aktif.

Cara pakai Client

Tab Client menampilkan daftar Client (dulu disebut Pembeli). Cari lewat kotak Cari nama / kode / WA / Catatan, filter status, dan urutkan lewat kotak Urutkan. Tiap Client = 1 outer card: inner card Data di atas (nama, paket, tanggal hangus, kode lisensi, WA, status, console), inner card Log abu di bawah (tersembunyi default, klik Lihat Log untuk buka, Sembunyikan Log untuk tutup). Tombol di card: Salin kode, Tempel console, Tandai sudah ditempel, Perpanjang, Cabut (lokal), Hapus.

Cara pakai Generator

Pilih paket Trial (gratis 7 hari), Langganan (Rp150rb / 3 bulan), atau Lifetime (Rp350rb, beli putus). Isi nama, WA, catatan, klik Generate kode baru, lalu klik Simpan Client supaya muncul di Client. Setelah itu ikuti kartu Hasil — tempel ke console: collection licenses, Document ID = kode (jangan Auto-ID), field semua string: type, expiresAt (kecuali Lifetime, field ini tidak dibuat), status active. Save, lalu klik Tandai sudah ditempel. Kalau Generate belum Simpan lalu pindah tab atau tutup app, draft-nya tersimpan dan muncul lagi saat app dibuka. Untuk kode yang sudah ada di console, pakai Tambah Client lama, isi kode dengan format ML-XXXX-XXXX-XXXX, paket, dan tanggal hangus, lalu Tambah.

Cara pakai Perpanjang dan Upgrade

Di card Client, klik Perpanjang. Kode lisensi sudah terisi otomatis. Tanggal hangus lama tampil sebagai pembanding. Klik +7 hari untuk Trial, +3 bulan untuk Langganan, atau isi tanggal manual. Klik Unlimited kalau Client upgrade ke Lifetime: paket berubah jadi Lifetime, tanggal hangus dihapus, bukan tambah tanggal. Klik Simpan perpanjangan, lalu ikuti kartu tempel console: untuk perpanjang, ubah 1 field expiresAt saja di dokumen yang sama; untuk upgrade, ubah type jadi lifetime dan HAPUS field expiresAt, status tetap active. Klik Tandai sudah ditempel setelah Save di console. Sampai ditandai, card tampil badge Belum ditempel. Di HP Client, kode tidak perlu diketik ulang, cukup buka app online atau Refresh.

Cara baca Log

Log ada di inner card abu di tiap Client, teks 9px, scroll di dalam card kalau sudah banyak baris. Satu baris per entri: nomor, waktu lengkap tanggal + jam, spasi lebar, aksi, lalu tanggal lama merah ke baru hijau di baris yang sama. Nomor urut dari 1, nomor 1 = entri paling lama di bawah, nomor paling besar = entri terbaru di atas. Nomor tidak berubah saat entri baru masuk. Contoh: 50 | 2026-10-28 09:40 | Diperpanjang 2027-01-28->2027-04-28. Log tersimpan lokal dan ikut backup, bukan di Firestore.

Cara pakai Setting

Setting berisi: Setup PIN (ganti PIN, setelah ganti PIN export backup baru, karena backup lama akan mengembalikan PIN lama saat restore), Cek / Scan APK (cek lokal: PIN, perangkat, jumlah Client, mau habis, habis, belum ditempel, backup terakhir; ingat, console tidak bisa diverifikasi dari app), Backup Data (export .json), Restore Data (pilih file, isi PIN backup, centang Update kalau mau timpa kode yang sudah ada, kalau tidak dicentang kode duplikat dilewati dan dilaporkan), Info Perangkat (Android ID terikat dan sumber), Kunci App Sekarang, Hapus Semua Data (konfirmasi ganda + centang sudah backup + PIN, Firestore tidak ikut terhapus), Tentang APK.

Backup, Restore, dan Pindah HP

Export backup secara berkala, simpan file .json di tempat aman, bukan cuma di HP ini. Restore di HP baru: dari layar kunci, pilih file backup + PIN lama, app akan mengikat ulang ke HP baru. HP lama tidak otomatis terhapus dari jauh, jadi sebelum HP lama dijual atau diberikan, hapus data lokal di HP lama. Kalau lupa PIN, satu-satunya jalan adalah restore backup + PIN lama.

Kalau ada masalah

  • Kode tidak valid di HP Client: cek dokumen di console, bukan status di app ini. Pastikan collection licenses, Document ID = kode, field string, type dan status active, dan expiresAt belum lewat (kecuali Lifetime tanpa expiresAt).
  • Perpanjang sudah disimpan tapi HP Client masih lama/habis: cek badge Belum ditempel di card Client, kemungkinan lo belum Save di console atau belum klik Tandai sudah ditempel.
  • App terkunci Perangkat tidak dikenali: HP ini bukan HP terikat. Masuk hanya lewat Restore Backup + PIN lama.
  • Restore 0 ditambahkan: kemungkinan semua kode sudah ada di daftar dan Update tidak dicentang, atau format kode di file salah. Cek laporan restore yang tampil setelah import.
  • Hapus Client di app ini tidak mencabut lisensi: untuk mencabut, klik Cabut (lokal), lalu ubah status di console jadi revoked, lalu Tandai sudah ditempel.
